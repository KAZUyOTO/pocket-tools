A few good things to know.

What can Pocket Tools do?

Convert images, PDFs, documents, audio, video, ebooks, fonts, 3D models and archives. Formats depend on the engines installed on your server. PDF editing, signing and merging are not currently included.

Where do my files go?

Standard conversions run on the server hosting Pocket Tools. Background removal, face enhancement and AI document recognition send files to configured Hugging Face services, with your agreement. Download files before the server’s retention window expires; the default is one hour.

Do I need an account?

No. Choose a tool and a file, then convert. Upload limits and supported formats are configured by the server operator.

Can I convert files on my phone?

Yes. Choose a file from your phone, select an output format, and download the result. The same tools work in your desktop browser.
